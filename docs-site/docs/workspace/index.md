# Workspace overview

The Operon workspace is divided into five main areas:

![The Operon workspace](../img/main-workspace.png)

| Area | What it does |
|---|---|
| **Activity bar** (left edge) | Switch between File Explorer, SSH, Git, Protocols, Help, Settings |
| **Sidebar** | Context-sensitive panel for the active activity-bar view |
| **Editor** (center) | Monaco-based code editor with 30+ language support |
| **Terminal** (bottom) | Integrated terminal with tab management — toggle with ++cmd+j++ / ++ctrl+j++ |
| **AI chat** (right) | Claude conversation panel with streaming responses — toggle with ++cmd+shift+j++ / ++ctrl+shift+j++ |

Every panel is resizable — drag the dividers to taste, or use the keyboard
shortcuts to hide what you don't need.
