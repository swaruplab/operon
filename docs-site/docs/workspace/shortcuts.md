# Keyboard shortcuts

Modifier shorthand: **Cmd** on macOS, **Ctrl** on Windows / Linux.

## Global

| Action | Shortcut |
|---|---|
| Settings | ++cmd++/`,` &nbsp;·&nbsp; ++ctrl++/`,` |
| Command palette | ++cmd+shift+p++ &nbsp;·&nbsp; ++ctrl+shift+p++ |
| Open folder | ++cmd+o++ &nbsp;·&nbsp; ++ctrl+o++ |
| Toggle sidebar | ++cmd+b++ &nbsp;·&nbsp; ++ctrl+b++ |
| Toggle terminal | ++cmd+j++ &nbsp;·&nbsp; ++ctrl+j++ |
| Toggle AI chat | ++cmd+shift+j++ &nbsp;·&nbsp; ++ctrl+shift+j++ |
| Toggle light/dark theme | (top-bar sun/moon icon) |

## File explorer

| Action | Shortcut |
|---|---|
| Quick file search | ++cmd+p++ &nbsp;·&nbsp; ++ctrl+p++ |
| Go to folder | ++cmd+g++ &nbsp;·&nbsp; ++ctrl+g++ |
| Project-wide search | ++cmd+shift+f++ &nbsp;·&nbsp; ++ctrl+shift+f++ |

## Editor

| Action | Shortcut |
|---|---|
| Save | ++cmd+s++ &nbsp;·&nbsp; ++ctrl+s++ |
| Find | ++cmd+f++ &nbsp;·&nbsp; ++ctrl+f++ |
| Replace | ++cmd+alt+f++ &nbsp;·&nbsp; ++ctrl+h++ |
| Toggle comment | ++cmd++/`/` &nbsp;·&nbsp; ++ctrl++/`/` |
| Close tab | ++cmd+w++ &nbsp;·&nbsp; ++ctrl+w++ |
| Cycle tabs | ++cmd+alt+right++ &nbsp;·&nbsp; ++ctrl+tab++ |

## Terminal

| Action | Shortcut |
|---|---|
| New terminal tab | ++cmd+n++ &nbsp;·&nbsp; ++ctrl+n++ |
| Clear terminal | ++cmd+k++ &nbsp;·&nbsp; ++ctrl+l++ |
| Copy selection | (auto on selection) |
| Paste | ++cmd+v++ &nbsp;·&nbsp; ++ctrl+shift+v++ (right-click also pastes) |

## AI chat

| Action | Shortcut |
|---|---|
| Send message | ++cmd+enter++ &nbsp;·&nbsp; ++ctrl+enter++ |
| Stop running session | ++esc++ |
| Switch mode | (dropdown at top of chat) |
| Toggle PubMed search | (in Ask mode — pill button) |
