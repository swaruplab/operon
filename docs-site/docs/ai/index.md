# AI assistant

Operon's chat panel talks to Claude (or a Claude-compatible model). The same
panel can drive four different **modes**, route through three different
**providers**, and ground itself in PubMed literature or custom MCP tools.

![AI modes dropdown](../img/ai-modes-dropdown.png){ width=400 }

## Pages in this section

- [Four modes](modes.md) — Agent / Plan / Ask / Report
- [Providers](providers.md) — Anthropic direct, Portkey gateways, or any
  OpenAI-compatible local backend
- [Private LLM stack](private-llm.md) — Ollama, vLLM, LM Studio for embargoed
  / clinical / NDA work
- [PubMed integration](pubmed.md) — cite real literature in your answers
- [MCP catalog](mcp.md) — typed tool access to PubMed, GEO, KEGG, GTEx,
