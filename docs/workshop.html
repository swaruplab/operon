About the workshop

What you'll leave with

By the end of the day you'll have used Operon to run three real analyses end-to-end — a bulk RNA-seq workflow on your own laptop, a single-cell pipeline over SSH on the UC Irvine HPC3 cluster, and a spatial transcriptomics walkthrough demonstrating Operon's most advanced agentic capabilities.

You'll also leave knowing when to reach for Agent vs. Plan vs. Ask vs. Report mode, how Operon's MCP integrations extend Claude with domain-specific tools, and how to keep sessions resumable across compute nodes and laptop restarts.

Open to graduate students, postdocs, PIs, and research staff working in genomics, single-cell, spatial biology, or adjacent fields. Seats are limited.

Session detail

What happens in each session

01 AI, AI Agents & Operon Architecture 10:00 – 10:45 · Lecture + demo · 45 min +

The opening lecture sets the conceptual foundation before any code is written. The first half (~20 min) covers what large language models are, what distinguishes an agent from a chat assistant (tool use, planning loops, autonomy), and why agentic workflows fit bioinformatics so well — multi-step pipelines, iterative debugging, code generation.

The second half (~25 min) walks through Operon's architecture: the Tauri / Rust / React stack, the role of MCP (Model Context Protocol) servers, how Claude is wired in as the agentic backbone, and the design decisions behind Agent, Plan, Ask, and Report modes. A short live demo closes the session so attendees see Operon in motion before they install it.

02 Hands-on Installation of Operon 10:45 – 11:45 · Hands-on · 60 min +

The goal: every attendee leaves with a working install before lunch. macOS is strongly preferred — it's Operon's primary platform and what we'll be teaching on. Windows is supported but in limited fashion; Windows attendees should expect a slower install path and a few rough edges.

The session covers download, first-launch setup, dependency checks, Anthropic API key entry (backup keys distributed on the day for those without one), and a 10-minute tour of the workspace. Two or three TAs will circulate to help; advanced attendees who finish early can be deputized as floating helpers.

03 Operon on Your Laptop · Bulk RNA-seq Downstream Analysis 12:45 – 2:00 · Hands-on · 75 min +

The first analysis session uses a pre-aligned bulk RNA-seq count matrix (a small mouse or human dataset of 6–12 samples) so the work fits comfortably on a laptop without HPC dependence.

Attendees ask Claude to perform QC, normalization, differential expression (pyDESeq2 or DESeq2), volcano and PCA plots, and a basic pathway enrichment. The session emphasizes iterative chat-driven analysis: ask, review the diff, accept, refine. The final 10 minutes inspect the auto-generated Report and discuss reproducibility.

04 Operon on HPC · Single-cell Analysis 2:15 – 3:30 · Hands-on · 75 min +

This session shifts from local to remote compute. Attendees connect Operon over SSH to UCI HPC3 (or their home institution's cluster if they bring credentials), open a tmux session, and run a single-cell pipeline on a real dataset (a 5,000–10,000 cell subset, pre-staged on HPC3 to avoid transfer time).

The workflow covers loading an h5ad, QC, normalization, dimensionality reduction, clustering, and basic cell-type annotation. 75 minutes is tight, so the dataset and notebook are pre-staged — the session is more about teaching the HPC connection pattern and resumable sessions than exhaustively covering single-cell methods.

05 Operon on HPC · Spatial Transcriptomics 3:45 – 4:30 · Hands-on + demo · 45 min +

The most advanced session, intentionally framed as a guided demo with light hands-on rather than full autonomous work. Recommended dataset: a single CosMx or Xenium tissue section subset, or a Visium sample.

The session demonstrates Operon's more advanced agentic capabilities — multi-step pipeline orchestration, MCP-server integration for tools like SpatialData, Sopa, or BANKSY — and serves as a "watch what Operon can do at the frontier of spatial biology" showcase. Attendees who fall behind in the hands-on portion can switch to follow-along mode without losing value.

06 Closing & Operon Enterprise 4:30 – 5:00 · Discussion · 30 min +

The wrap-up covers three things: a recap of common gotchas observed during the day; a forward look at Operon Enterprise (licensing model, on-premise / private-LLM deployment for institutional data, custom MCP integrations, support tiers); and an open discussion about where attendees see Operon fitting into their own workflows.

The closing slide includes GitHub, documentation, and an invitation to join the community for follow-up support.

What to bring

  • A Mac laptop is strongly preferred (macOS 12 Monterey or later, 8 GB RAM, ~5 GB free disk). Windows is supported but limited — expect a rougher install experience and a few features that don't yet have parity.
  • SSH credentials for an HPC cluster — UCI affiliates: a guest HPC3 account can be arranged if requested at registration
  • Optional: a dataset you actually want to analyze — FASTQ, BAM, h5ad, count matrix, microscopy image, anything. We'll have pre-staged datasets for those without one.
  • An Anthropic API key, or we'll get you set up with one on the day

Prerequisites

None. If you've ever opened a terminal you'll be fine. The workshop is designed so an experimental biologist who writes no code and a computational postdoc who writes pipelines every day both leave with something useful.

Taught by the Swarup Lab

Operon is developed at the Swarup Lab at UC Irvine — a neurogenomics group running single-cell, spatial, and epigenomic experiments in Alzheimer's disease. The workshop is led by the team that builds Operon day-to-day.
